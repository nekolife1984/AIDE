# レビュールール

## 指摘の基準

- 変更範囲内の不具合、要件未達、セキュリティ問題、重要な検証漏れを優先。
- 実害・根拠・対応案を示せる指摘に限定。推測、好み、軽微な書式、範囲外の改善は指摘しない。
- 同じ内容を重複して指摘しない。問題箇所と影響を具体的に記載する。

## 指摘の区分

- **必須**：修正しないと正しさ・安全性・完了条件を損なうもの。マージ前の対応対象。
- **提案**：任意の改善。採用は作者の判断。

## 指摘への対応

- 作者は指摘・提案を採用しない判断ができる。PR上で理由を説明する。
- 必須指摘への異議は根拠を示して確認し、合意または責任者の判断まで未解決として扱う。
- 修正した指摘は変更内容と確認結果を返信する。
